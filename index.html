Flow Processing Unit (FPU)

A custom dataflow accelerator from GonidonCloud, purpose-built for high-throughput, pipelined stream processing workloads.

Get started → Explore the architecture

What is the FPU?

The Flow Processing Unit (FPU) is GonidonCloud's domain-specific accelerator for flow-based computing. Instead of executing instructions sequentially over fetched data, the FPU organizes computation as a graph of processing stages connected by literal data flows. Tokens — packets of data — stream through these stages continuously, which means the device can be fully utilized the moment data is available.

Where a traditional CPU optimizes for latency on general-purpose code and a GPU optimizes for massive SIMD parallelism, the FPU optimizes for sustained throughput on deterministic data-pipeline workloads: stream analytics, signal and image processing, feature pipelines for ML, encryption, compression, and packet inspection.

info
Note
The name may look familiar: FPU historically stood for Floating-Point Unit. In GonidonCloud hardware, it stands for Flow Processing Unit — a deliberate tribute to the idea of dedicated silicon for one class of computation.

Key features

🌊

Dataflow execution

Computation is expressed as a static pipeline graph; data flows between stages with no instruction fetch overhead.

⛓️

Deep pipeline

Up to 256 concurrent stages per core, each stage independently clocked and power-gated.

📦

Stream-native I/O

Peripherals communicate over GonidonCloud FlowFabric links at up to 400 Gbps per port.

🧩

Reconfigurable stages

Runtime-swappable stage kernels let one device serve many pipeline templates without reflashing firmware.

How the FPU is different

Aspect CPU GPU FPU
Execution model Sequential instructions Bulk synchronous parallel Asynchronous dataflow graph
Best suited for General-purpose logic Dense math on large batches Continuous streams and pipelines
Data locality Cache hierarchy Shared memory / HBM Stage-local flow queues
Bottleneck Instruction fetch & branch misses Kernel launch & synchronization Backpressure at flow boundaries
