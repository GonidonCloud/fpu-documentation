Quickstart: your first pipeline

Go from an empty workstation to a running FPU pipeline in about ten minutes.

On this page
  1. Before you begin
  2. Install the toolchain
  3. Verify the device
  4. Write a pipeline
  5. Place and run

Before you begin

  • A Linux host (Ubuntu 22.04+ or RHEL 9) with an FPU device installed, or access to a GonidonCloud FPU VM.
  • Python 3.10 or later.
  • The gonidon repository access token (provided in your GonidonCloud console).
info
Note
No hardware yet? The toolchain includes fpu-sim, a cycle-accurate simulator that runs every example on this site on your CPU.

Install the toolchain

curl -fsSL https://get.gonidon.cloud/fputool | sh

# Adds the fputool binary to ~/.gonidon/bin
export PATH="$PATH:$HOME/.gonidon/bin"

This installs:

  • fputool — compile, place, and inspect pipelines.
  • fpu-sim — cycle-accurate device simulator.
  • flangd — the FlowLang language server.

Verify the device

fputool probe

On a host with an FPU v2 device attached you should see:

Device 0: FPU v2 "Tisza"       [OK]
  Flow cores:  32 / 32 healthy
  HBM:         32 GB (26% reserved by host service)
  FlowLink:    4 ports up (400 Gbps each)
  Temperature: 41 °C — nominal

Write a pipeline

Create hello.flow:

// hello.flow — uppercase a stream and count tokens
source stdin
  --> map upper            { kernel = "utf8_upper" }
  --> tee {
        branch 0 --> sink stdout,
        branch 1 --> reduce count { kernel = "count64" }
                      --> sink metrics
      };

This declares three stages — a map, a fan-out tee, and a reduce — wired in a static graph. No scheduler, no threads.

Compile and run

fputool build hello.flow --target=sim    # for fpu-sim
fputool build hello.flow --target=v2     # for real silicon

fputool run hello.flow

Type into the terminal and watch the transformed text echo back. Press Ctrl+C to end the stream; the metrics sink prints the final count.

warning
Warning
Running against real hardware requires a signed bitstream. Development builds work on fpu-sim and, with an unlocked device, on engineering samples only.
