FIRST PROGRAM

Run a tensor program

Install FlowKit, verify your FPU target, and execute a compiled operation on hardware or the simulator.

On this page
  1. Prerequisites
  2. Install the toolchain
  3. Discover a target
  4. Compile and run
  5. Save and reload a binary
  6. Troubleshooting

Prerequisites

  • Linux on an x86-64 or Arm64 host.
  • Python 3.10 or newer and pip.
  • Access to the GonidonCloud FPU package repository.
  • An FPU device with its host driver installed, or no hardware if you use the simulator.

The examples use only FlowKit and NumPy. They do not require a separate machine learning framework.

Install the toolchain

Create an isolated Python environment:

python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install flowkit flowkit-tools numpy

The packages provide the following components:

ComponentPurpose
flowkitPython API for tensor construction, compilation, and execution.
flowcStandalone compiler and FlowModel importer.
fputoolDevice discovery, diagnostics, and profiling.
fpu-simFunctional simulator selected with FLOW_TARGET=sim.

Confirm that the compiler and runtime versions match:

flowc --version
fputool version

Discover a target

fputool status

An M2 host reports output similar to this:

DEVICE  TARGET   DRIVER   HEALTH   CLUSTERS   HBM AVAILABLE
0       fpu-m2   2.4.1    OK       4          91.6 GiB

FlowMesh: 4 links up · workgroup membership: local
Runtime:  2.4.1 · default device: 0
i
No device required
Set FLOW_TARGET=sim to run the same example on the functional simulator. The simulator checks numerical behavior and shapes, but it must not be used for performance estimates.

Compile and run

Create a file named vector_add.py:

import numpy as np
import flowkit as fk

# Python values describe the computation captured by the compiler.
def add_tensors(x, y):
    return fk.add(x, y)

spec = fk.TensorSpec(shape=(1024, 1024), dtype="float32")
program = fk.compile(add_tensors, x=spec, y=spec)

rng = np.random.default_rng(42)
x_host = rng.standard_normal((1024, 1024), dtype=np.float32)
y_host = rng.standard_normal((1024, 1024), dtype=np.float32)

x_device = fk.to_device(x_host)
y_device = fk.to_device(y_host)
result_device = program(x_device, y_device)
result_host = fk.from_device(result_device)

np.testing.assert_allclose(result_host, x_host + y_host, rtol=1e-6)
print(f"Target: {fk.current_target()}")
print(f"Output: {result_host.shape}, {result_host.dtype}")
print("Result matches NumPy")

fk.compile captures the operation and produces an executable for the current target. fk.to_device allocates device memory and copies each input. fk.from_device waits for pending work and retrieves the result.

Run on the default FPU:

python vector_add.py

Or select the simulator:

FLOW_TARGET=sim python vector_add.py

Expected final line:

Result matches NumPy
!
Device calls are asynchronous
Compilation is synchronous, but program launches are not. Use result_device.block_until_ready() when measuring execution time without copying the result to the host.

Save and reload a binary

Save a compiled executable when you want deployment to skip compilation. Add these lines to the example after program is created: 

program.save("vector_add.flb")
restored = fk.load("vector_add.flb")
result_device = restored(x_device, y_device)

A Flow binary records its target, input specifications, and output specifications. The runtime rejects incompatible arguments before launching the program. Binaries are not portable between different FPU targets; retain the source and compile once per target.

Troubleshooting

SymptomWhat to check
No FPU target foundRun fputool status, verify driver permissions, or set FLOW_TARGET=sim.
Shape mismatchCompare input shapes and dtypes with the TensorSpec used at compile time.
Target mismatchRecompile the program for the target reported by fputool status.
HBM allocation failedRelease unused device arrays and inspect allocations with fputool memory.

For a diagnostic bundle, run fputool doctor --output fpu-diagnostics.tar.gz. Review the bundle before attaching it to a support request.
